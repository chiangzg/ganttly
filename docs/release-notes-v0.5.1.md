# ganttly v0.5.1 — 行级键盘导航、依赖层级显示与 WBS 截断修复

> v0.5.0 之后的体验补丁：任务表与资源表支持方向键流畅导航与展开/收起、依赖选择器显示完整任务层级路径、修复深层级 WBS 编号被裁剪以及任务表与画布行未对齐的问题。

🎨 **在线 demo**:https://chiangzg.github.io/ganttly/

---

## 主要特性

### 行级键盘导航

任务表与资源表支持纯键盘操作，方向键语义对称、可流式连续触发，无需鼠标即可浏览整棵任务树。

| 能力               | 说明                                                                                                     |
| ------------------ | -------------------------------------------------------------------------------------------------------- |
| **↑ / ↓ 上下移动** | 在可见行间切换选中，自动滚动到可视区，跳过不可选的分隔行                                                 |
| **→ 流式展开**     | 展开当前折叠节点；若当前已展开或为叶子，则向下找第一个折叠节点展开。整棵树都已展开时无操作               |
| **← 流式收起**     | 收起当前已展开节点；若当前无可收起子树，则向上找第一个已展开节点收起。整棵树都已收起时无操作             |
| **共享工具库**     | 新增 `lib/rowKeyboardNavigation.ts`（`adjacentSelectableRow` / `focusAndRevealRow`），任务表与资源表共用 |
| **资源视图适配**   | 资源表同样支持方向键导航，→ / ← 下钻任务行或展开/收起资源分组                                            |

### 依赖选择器显示完整任务路径

任务抽屉的依赖关系区域，从只显示任务名改为显示 **WBS 编号 + 完整层级路径**，便于在同名任务中区分。

- 新增 `buildTaskHierarchyLabels`，基于 `buildTree` + `flattenAll` 生成 `1.1.1 项目甲 / 后端开发 / 发布` 形式的标签。
- 已选依赖展示与 `DependencyAdder` 下拉项均使用该标签。

### 缺陷修复

| 问题                           | 原因                                              | 修复                                                                     |
| ------------------------------ | ------------------------------------------------- | ------------------------------------------------------------------------ |
| **深层级 WBS 编号被截断**      | WBS 列宽固定 44px，嵌套任务（如 `3.1`）被裁成 `3` | 改为按真实缩进 + 控件 + 编号长度动态计算列宽，任务名列弹性吸收余量       |
| **任务表行与画布行未垂直对齐** | 任务搜索栏未计入表头高度，挤占了列头空间          | 搜索栏纳入表头总高（HEADER_HEIGHT 56px），列头占剩余高度，与画布首行对齐 |

## 技术实现

| 模块                                       | 说明                                                                                                         |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| **`lib/rowKeyboardNavigation.ts`**（新增） | 两个纯函数：`adjacentSelectableRow` 在可选行索引序列中定位相邻行；`focusAndRevealRow` 聚焦并按需滚动到可视区 |
| **`TaskTable.tsx`**                        | 接入方向键导航；WBS 列宽改用 `wbsWidth` useMemo 动态计算；搜索栏与列头共享 HEADER_HEIGHT                     |
| **`ResourceList.tsx`**                     | 接入方向键导航，复用同一工具库，跳过 `task-header` 分隔行；行新增 `aria-selected`、`data-resource-id` 等属性 |
| **`TaskDrawer.tsx`**                       | 新增 `buildTaskHierarchyLabels`，依赖展示与下拉项使用层级标签                                                |

## 不变项

- `GanttlyFile` 数据 schema **仍为 v1**，本期不新增字段、不提升 `schemaVersion`。
- 关键路径、基线比较、视图切换、撤销 / 重做 / 保存等既有逻辑均无变更。
