# ganttly v0.8.1 — 远端项目深链接刷新修复

> v0.8.0 之后的修复版:刷新远端项目编辑页永久卡在「正在加载项目中…」的一处修复。

🎨 **在线 demo**:https://chiangzg.github.io/ganttly/

---

## 主要修复

| 问题                              | 修复                                                                                                                                                                                                                        |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **刷新远端项目页永久卡加载**(#17) | 会话 cookie 有效但 auth 内存态随刷新清空,编辑页此前不补会话校验,repo 解析失败又在任何状态写入前早退,`loadState` 停留 `idle` 落入永久 spinner。现在编辑页刷新先 `checkAuth` 再加载;任何失败路径都落地为终态错误,不再可能卡死 |

## 一并改进

- **编辑页内联登录卡**:未登录状态打开远端项目深链接,直接在编辑页给出登录入口(开发登录/GitHub),登录成功精确回跳原项目,不再要求"回项目中心重新进入"
- **OAuth 回跳尊重深链接**:登录后优先回到登录前所在页面(此前一律跳第一个工作区)
- **会话过期文案**:保存/加载遇到 401 显示「登录已过期,请重新登录」,不再暴露原始错误码

## 测试

- web typecheck / lint / build 全绿,CI(Lint/Typecheck/Build/单测 + Playwright E2E)通过
- 浏览器实测四场景:远端编辑页 F5 直接加载;登出后深刷 → 登录卡 → 回跳原项目;本地项目深刷不受影响;深刷页面内新建/撤销任务正常保存

## 不变项

- **本地优先**:数据默认存浏览器 IndexedDB,零后端、零运维的形态不变
- `GanttlyFile` 数据 schema **仍为 v1**,无需迁移
