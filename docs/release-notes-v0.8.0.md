# ganttly v0.8.0 — WBS 任务树与资源明细栏交互现代化

> v0.7.1 之后的功能版:编辑器左栏全面现代化。任务树( #14 )与资源明细栏( #15 )遵循同一套交互语言——hover 零位移、双击语义统一、点击后才编辑、仅把手可拖拽——并按「任务视图以任务为主、资源视图以人为主」各自适配。

🎨 **在线 demo**:https://chiangzg.github.io/ganttly/

---

## WBS 任务树(#14)

| 变更                    | 说明                                                                                                                                    |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **WBS 列扁平化**        | 编号不再随层级缩进,固定起点全表垂直对齐;列宽按最长编号自适应,深层编号无截断                                                             |
| **树形移入任务名称列**  | 层级参考线 + 箭头槽全行保留,父任务「箭头 + 半粗 + 底色 + 参考线」四重信号,父/叶子任务一眼可辨,同级名称严格对齐                          |
| **双击语义统一**        | 双击行任意普通位置 = 打开详情抽屉,消除「双击名字重命名、双击空白开详情」的隐藏分区规则;行内编辑改走 `F2`(+`Tab` 跳字段)与右键「重命名」 |
| **仅把手可拖拽**        | 行首 18px 把手槽 hover 淡入,是行上唯一拖拽源;拖拽重排/改层级带插入线、`Escape` 取消、边缘自动滚动,单击/双击永不误触拖拽                 |
| **折叠徽标 + 批量展开** | 折叠的父任务显示「N 项」子任务计数;搜索栏新增全部展开/收起;hover 相关的显隐只改 opacity,任何元素不再位移                                |
| **treegrid 可访问性**   | 行容器 `role="treegrid"`,行 `aria-level`/`aria-expanded`,箭头按钮带标签与状态                                                           |

## 资源明细栏(#15)

| 变更                    | 说明                                                                                                                                                             |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **姓名头像圆标**        | 资源行显示按姓名取色的圆形缩写(孟/ZS/AC),明暗主题均柔和——资源视图「以人为主」的身份标识                                                                          |
| **点击后才编辑**        | 名称/角色/容量由常驻输入框改为静态文本;`F2` 或右键「重命名」进入编辑,`Tab` 在 名称→角色→容量 间跳转,**一次提交只产生一条 undo 记录**(旧版每敲一键进一次 undo 栈) |
| **双击 = 下钻**         | 双击资源行展开/收起其名下任务明细;折叠时显示「N 项」徽标;任务 lane 双击仍打开任务抽屉                                                                            |
| **把手拖拽重排**        | 同款把手拖拽重排资源顺序,一次拖拽 = 一条 `moveResourceCommand`(可 undo);`×` 删除按钮改 hover 淡入,`Delete` 键弹确认                                              |
| **右键菜单 + 批量展开** | 资源行右键:重命名 `F2` / 展开收起 / 新增资源 / 删除资源;表头新增全部展开/收起;与任务树一致的 treegrid aria                                                       |

- 存量 e2e 全量同步选择器;**e2e 202/202、单测 403/403** 全绿,CI(Lint/Typecheck/Build/单测 + Playwright E2E)通过

## 不变项

- **本地优先**:数据默认存浏览器 IndexedDB,零后端、零运维的形态不变
- `GanttlyFile` 数据 schema **仍为 v1**,无需迁移(资源排序复用既有数组顺序,未加字段)
