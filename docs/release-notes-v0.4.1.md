# ganttly v0.4.1 — 编辑器导航与工具栏重构

> 对编辑器顶部导航（项目头部 + 工具栏）进行系统性重构：按语义分组、图标化、按视口宽度响应式折叠次要开关，并补齐保存状态指示与键盘可达性。

🎨 **在线 demo**:https://chiangzg.github.io/ganttly/

---

## 主要特性

### 响应式工具栏（核心改进）

把原来横向滚动、所有按钮挤在一行的工具栏，重构为按语义分组、随视口宽度优雅折叠的现代工具栏。

| 能力             | 说明                                                                                         |
| ---------------- | -------------------------------------------------------------------------------------------- |
| **语义分组**     | 按「日期导航 / 计划显示 / 视图 / 编辑操作」分组，操作更易扫读                                |
| **图标化**       | 按钮统一引入 lucide 图标（今天 / 缩放 / 关键路径 / 视图 / 人天列 / 撤销 / 重做 / 保存）      |
| **缩放分段控件** | 缩放改为 `− [档位] +` 分段控件，档位居中显示，替代原来的纯文字按钮                           |
| **视口断点折叠** | `lg` 断点隐藏缩放与计划显示组；`xl` 断点隐藏关键路径 / 人天列 / 基线，统一折叠进「更多」菜单 |
| **保存状态指示** | 保存按钮改为图标，根据 `saveState` 显示 saving（旋转）/ saved（对勾）/ error（警示红）状态   |
| **主操作高亮**   | 「新建任务」改为 `primary` 变体，视觉上突出主动作                                            |

### 项目头部（ProjectHeader）

| 改动                       | 说明                                                             |
| -------------------------- | ---------------------------------------------------------------- |
| **圆角与边框统一**         | `rounded-xl` → `rounded-lg`、边框透明度统一为 `border-border/80` |
| **标签页底部下划线激活态** | 激活标签页改为底部下划线指示，移除描边，更贴近现代浏览器标签风格 |
| **键盘可达性**             | 全局按钮补充 `focus-visible:ring`，焦点环统一为 `primary/35`     |

### 基础组件

| 改动                            | 说明                                                                            |
| ------------------------------- | ------------------------------------------------------------------------------- |
| **ToolbarButton 变体**          | 新增 `variant`（ghost / subtle / primary）与 `size`（icon / compact / default） |
| **ToolbarDivider / ExportMenu** | 支持自定义 className；导出项铺满菜单宽度，视觉对齐                              |

### 基线控制（BaselineControl）

新增 `presentation` 属性：`toolbar`（原有下拉）与 `menu`（子菜单），用于在「更多」菜单中以子菜单形式复用同一份基线菜单内容，避免重复实现。

## 技术实现

| 模块                  | 说明                                                                                                                          |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| **`Toolbar.tsx`**     | 完全重写工具栏布局：`ToolbarGroup` 分组、断点 class、`forceMount` + `data-[state=closed]:hidden` 实现「更多」菜单的响应式区块 |
| **`BaselineControl`** | 抽出 `menuContent`，按 `presentation` 在 `DropdownMenu.Root` 与 `DropdownMenu.Sub` 间切换                                     |
| **`ToolbarButton`**   | 基于 `variant` / `size` 组合样式；`pressed` 在非 primary 变体下用 `bg-primary/10`                                             |
| **`GanttView`**       | 用 `data-editor-navigation` 包裹头部 + 工具栏，便于测试定位与断言                                                             |

## 不变项

- `GanttlyFile` 数据 schema **仍为 v1**，本期不新增字段、不提升 `schemaVersion`。
- 所有功能行为（关键路径、基线比较、视图切换、撤销 / 重做 / 保存）均无逻辑变更，仅调整呈现与布局。

## 测试

- **E2E**：新增 `navigation.spec.ts`，覆盖桌面（1440）完整可见、中等视口（1024）折叠次要开关、窄视口核心操作等响应式断言，并附明 / 暗主题截图快照。
- 全套 `pnpm typecheck` / `lint` / `test` / `pnpm build` 通过。
