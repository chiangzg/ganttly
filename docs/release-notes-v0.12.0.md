## 新特性：依赖链高亮（#35）

### 一句话用法

单击一个任务（画布或左侧任务树），它的**全部传递依赖链**就会高亮；点空白处、按 Esc 或改选其他任务即切换或消失——零新手势、零学习成本。多选（⌘/Ctrl/Shift）时不显示，不干扰批量操作。

### 向前（前置 · 已完成路径）— 静止的翡翠绿

这个任务**依赖了谁**：翡翠绿实线 + 柔和宽底光，沉稳的"已落地"质感，无任何运动；链上任务条加同色描边。回答"之前完成了什么、动它之前要确认什么"。

### 向后（后续 · 向下传递）— 流动的青色脉冲

这个任务**被谁依赖**：青色实线 + 白色流动虚线，一枚辉光脉冲点沿路径游走，并**按拓扑深度逐层错峰启动**——涟漪从被点任务一层层传向未来，直观表达"向下传递"。回答"未来要做什么、改它会影响谁"。

### 聚光灯与图例

- 无关任务条降至 ~45% 透明、无关箭头近乎隐去，链路成为舞台焦点；链成员的**祖先摘要条保持全亮**，WBS 上下文不丢
- 被点任务（origin）保留主色选中环 + 呼吸光晕——涟漪的源头
- 画布右下角玻璃拟态图例：双色语义说明 + 「N 个前置 · M 个后续」计数

### 工程细节

- **优先级安全共存**：边样式优先级为 冲突橙 > 链路色 > 关键红 > 常规灰；约束冲突的橙色错误标记永不淡化，与关键路径开关、基线对比、搜索过滤并行不悖
- **数据语义**：按原始依赖图（非 CPM 叶子图）计算传递闭包，双向 BFS 取最短深度驱动脉冲错峰；容忍存量数据中的成环、缺失引用与摘要级依赖
- **性能**：闭包每次场景组装算一次（O(V+E)，与关键路径同量级）；脉冲动画走按需 rAF 循环——仅当下游链非空才运行，成本≈一次滚动 tick；零选中零开销
- **可访问性**：`prefers-reduced-motion` 下自动降级为静态虚线 + 静止光晕，不启动动画循环
- 领域包新增 `computeDependencyClosure`；设计文档见 `docs/dependency-chain-highlight-spec.md`

## 远端协作：改任务不再误弹「远端有更新」（#34）

远端模式下只要改动任务（状态/进度、日期、名称、拖拽），顶部就弹粘性黄色横幅「远端有更新」，且每次保存的 SSE 回推触发整项目重载、**清空 undo/redo**、还会静默丢弃重载飞行途中的并发编辑。

根因：服务端把保存事件广播给 workspace 全部 SSE 连接（**含写入者自己**），而旧判定只看本地 dirty 标志——自己写入的回推（self-echo）被当成外部协作者的修改。

修复：新增唯一判定入口 `handleRemoteChange`——有在飞保存先等落地再比较 revision（自回推可先于 PUT 响应到达），`事件 revision ≤ 本地 revision` 判为自回推直接忽略；`reloadFromRemote` 加两道并发守卫（飞行途中新编辑绝不覆盖、revision 落后不采纳）。本地模式零变化；同一用户多 tab 的真实冲突仍正常弹横幅。

## 日历：2026 国庆按官方通知修正（#36）

对照《国务院办公厅关于 2026 年部分节假日安排的通知》修正 zh-CN 日历两处偏差：

1. **删除多余的 10月8日假期**——官方国庆为 **10月1日（周四）至7日（周三）共 7 天**，10-08 是正常工作日
2. **调休上班日 9月19日（周六）→ 9月20日（周日）**——原数据把补班日写错了一天

**对存量项目的影响**：跨国庆的工作日计算会变化——10-08 变为工作日（假期后首个工作日从 10-09 提前到 10-08）、9-20 变为上班日、9-19 恢复休息。涉及工期、排期级联、基线偏差等所有走日历的路径，相关任务的日期/工期展示可能随之变化，**这正是修正目的**。2026 年其余节假日已一并核对，均与官方一致。
