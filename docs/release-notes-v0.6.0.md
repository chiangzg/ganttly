# ganttly v0.6.0 — 甘特图任务过滤、依赖箭头路由优化与里程碑锚点修正

> v0.5.1 之后的小版本：甘特图画布支持按条件动态过滤可见任务、依赖箭头避障路由进一步优化避免绕远、里程碑锚点从起始线修正至结束线。

🎨 **在线 demo**:https://chiangzg.github.io/ganttly/

---

## 主要特性

### 甘特图任务过滤

甘特图画布支持任务过滤，可按条件动态控制哪些任务在时间轴上渲染，聚焦关心的任务子集。

| 能力               | 说明                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------ |
| **动态过滤**       | 引入 `taskFilter`，在画布层按条件筛选任务，过滤后画布仅渲染可见任务                  |
| **可见任务树构建** | 新增 `buildTree` 与 `flattenVisible`，基于过滤结果重建可见任务树并扁平化为渲染行序列 |
| **滚动高度修正**   | 修正最大滚动高度，扣除固定表头（`HEADER_HEIGHT`）占用区域，过滤后画布尺寸与行数一致  |

## 缺陷修复

| 问题                   | 原因                                                                     | 修复                                                                                                                               |
| ---------------------- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| **依赖箭头路由绕远**   | 避障路由在某些布局下选择了不必要的迂回路径                               | 合并并优化依赖箭头避障算法，优先选择更短、更直的路由，避免绕远                                                                     |
| **里程碑锚点位置偏移** | 里程碑（零工期节点）锚定在当天起始线（左边界），与"当天结束"的语义不一致 | 引入 `milestoneCenterX` 计算里程碑中心点，将其锚定至当天结束线（右边界），并同步更新渲染、依赖箭头路由、悬停碰撞检测及相关单元测试 |

## 技术实现

| 模块                  | 说明                                                                                                               |
| --------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **`GanttCanvas.tsx`** | 接入 `taskFilter`；新增 `buildTree` / `flattenVisible` 构建可见任务树；修正 `HEADER_HEIGHT` 参与的最大滚动高度计算 |
| **`engine`**          | 新增 `milestoneCenterX`，统一里程碑中心点计算；依赖箭头路由、悬停碰撞检测同步引用该中心点                          |

## 不变项

- `GanttlyFile` 数据 schema **仍为 v1**，本期不新增字段、不提升 `schemaVersion`。
- 任务表 / 资源表的方向键导航、依赖层级路径显示、基线比较、视图切换、撤销 / 重做 / 保存等既有逻辑均无变更。
