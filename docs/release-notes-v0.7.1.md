# ganttly v0.7.1 — 资源负载与远端工作区修复

> v0.7.0 之后的修复版：资源视图主任务负载重复计算、远端归档/恢复幂等键、项目目录切换竞态与回收站导航共四处修复。

🎨 **在线 demo**:https://chiangzg.github.io/ganttly/

---

## 主要修复

| 问题                              | 修复                                                                                                                                                                                           |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **资源视图负载凭空 +100%**(#11)   | 任务先分配负责人再挂子任务后,主任务的残留 assignment 被负载计算重复计入。`computeResourceLoad` 现按 `cost.ts` 同款 summaryIds 模式跳过主任务(含多层嵌套),hover 贡献列表同步过滤;存量数据免迁移 |
| **远端归档/恢复重试报 422**(#12)  | `moveToTrash`/`restoreProject` 的非幂等 POST 补发 `Idempotency-Key` 头,网络重试不再被服务端契约拒绝                                                                                            |
| **切回本地后项目列表被清空**(#12) | 目录刷新加作用域守卫:切走工作区后仍在途的慢响应直接丢弃,不再覆盖当前列表(此前需手动刷新恢复);新增 fake-indexeddb 竞态回归测试                                                                  |
| **远端回收站导航跳错工作区**(#12) | "返回项目中心"/"回收站"改为跳转当前作用域,不再硬编码回本地                                                                                                                                     |

## 测试
