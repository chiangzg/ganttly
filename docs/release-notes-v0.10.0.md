# ganttly v0.10.0 — 编辑任务抽屉交互重构

> v0.9.0 之后的功能版:编辑任务抽屉从「能用」升级到「顺手」——依赖/资源搜索即添加、资源拼音首字母搜索、预设色卡,整体重组为五分区布局。一并合入两个远端实例发现的 CORS 误报修复。

🎨 **在线 demo**:https://chiangzg.github.io/ganttly/

---

## 编辑任务抽屉:三大高频交互重做

### 依赖:搜索即添加(不再有「+」)

原来的「下拉选任务 → 点右侧加号」两步流,是日常使用中最容易忘记最后一步的地方。现在是一个搜索框:**点开、输入、选中,依赖立即生效**——浮层保持打开,可连续添加多条。类型(FS/SS/FF/SF)与滞后量在添加后的行上直接修改。

### 资源分配:拼音首字母搜索

同样是选中即分配(默认负载 50%)。搜索支持**拼音首字母**(输入 `jzg` 命中「蒋志国」)、全拼、原文以及角色字段;分词组合匹配(`jiang zhi` 也能命中)。已分配的资源自动从候选中排除。

### 颜色:预设色卡 + 系统取色器

不再要求手输 RGB:一行色卡,「默认」格一键回到主题默认色,10 个明暗双主题下都可读的预设色,末尾彩虹格调起**系统取色器**(macOS/Windows 自带吸管),想输 hex 也随你。

## 整体布局:五分区

抽屉从「平铺字段 + 高级折叠」重组为:**基本信息 / 资源分配 / 依赖 / 约束 / 样式与备注**,资源区上移、总人天常驻节标题右侧。顺手的打磨:

| 改进                 | 说明                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------ |
| **成环即提示**       | 会形成循环的依赖照常进入草稿但**行内标红**,保存按钮禁用并给出原因——不再弹 alert 打断 |
| **加班日选中即生效** | 选好日期直接加入 chip,范围/休息日校验错误就地显示;「添加」按钮删除                   |
| **里程碑开关**       | checkbox 样式化为 switch;进度支持滑条 + 数字框双向输入                               |
| **校验错误行内化**   | 错误显示在对应字段下方(顺带修复了旧版错误文案显示为原始 i18n key 的问题)             |
| **图标统一**         | 裸字符 `+`/`✕` 全部换成 lucide 图标                                                  |

**不变**:草稿事务语义(编辑不落库、保存 = 一条 undo、脏守卫、切换任务确认)与上一版完全一致。

## 一并合入:远端实例发现 CORS 修复

- **修复「添加远端服务」误报 URL 错误**:发现端点实际开放只读跨域时,前端不再误判为服务不可用
- **区分「不可达」与「可达但跨域被拦」**:新增 no-cors 可达性探测,提示语与处置建议分开,不再把 CORS 配置问题当成地址填错

## 升级与文档

- 自建实例:`git pull && docker compose up -d --build`,**零数据库迁移**、schema 仍为 v1;新增前端依赖 `pinyin-pro`(纯前端,无服务端变更)
- GitHub Pages 随 main 推送自动部署

- typecheck / lint / build 全绿;已在本机 dev 环境对真实数据做过视觉与交互走查

## 不变项

- `GanttlyFile` 数据 schema **仍为 v1**,无需迁移;**零数据库迁移**
